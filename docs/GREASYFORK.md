# 论坛译读 · Forum Translator

在 Reddit 与 X/Twitter 的原文下逐段追加中文译文，阅读时积累六级及以上词汇。

## 主要功能

- Google / Microsoft / AI Responses 翻译服务可选，原文、链接、代码和段落保留。
- AI 正文翻译与词汇分析共用一次请求，译文流式显示，词汇随后出现，无词时不占位。
- 音标、语境释义、英语朗读、双语例句、收藏和间隔复习。
- 可见首帖优先，其他内容合批并发；滚动不反复中断请求，本地缓存复用已完成内容。
- X 侧栏收纳，广告与浮动入口隐藏开关，图片和视频等比缩放、独立尺寸记忆，引用帖同样适用。

- Reddit 图片和视频支持等比缩放，与 X 分别记忆尺寸；自动隐藏信息流和详情页广告。

## 使用

安装后打开 Reddit 或 X，默认使用 Google 自动翻译。油猴菜单中选择「Reddit 翻译设置」或「X 翻译设置」调整服务、预加载范围和显示方式。

AI 功能需要自行配置兼容 Responses API 的 Base URL（含 `/v1`）、API Key 和模型。词汇由模型筛选，不等同于官方词表认证。思考深度默认 low；Fast 是否生效取决于接口和账户支持。使用公共翻译服务时，词汇分析仍需要另外配置 AI。

## 数据与权限

默认自动翻译视口及预加载范围内的文本。Google / Microsoft 翻译将文字发送至所选公共服务；AI 将当前待译内容和必要上下文发送至你配置的接口。AI 可能产生费用，数据保留由服务商决定。

密钥、译文缓存、收藏和尺寸设置保存在当前脚本存储中。密钥不会写入源码或译文缓存，脚本存储本身不加密。`@connect *` 用于自定义 AI 服务域名；只匹配 Reddit 与 X/Twitter。媒体缩放不上传图片或视频。

推荐新版 Chrome / Edge。网站改版、公共接口限流和模型输出质量可能影响使用；朗读依赖系统语音。
